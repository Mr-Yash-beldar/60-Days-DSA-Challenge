# 🔹 Part 1: Insertion Sort

## 🔹 Question 1: Implement Insertion Sort

**Description:**  
Given an array, sort the elements in ascending order using the Insertion Sort algorithm.

**Input:**

```bash
5
5 3 4 1 2
```

**Output:**

```bash
1 2 3 4 5
```
