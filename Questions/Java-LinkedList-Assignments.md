## 🔹 Assignment 1: Basic LinkedList

<badge>Easy</badge>

- Add 5 numbers.
- Print all numbers.

## 🔹 Assignment 2: Student Management

Create a `LinkedList` containing the following student names:

```java
["Rahul", "Amit", "Priya", "Sneha"]
```

Perform the following operations:

- Add `"Yash"` at the beginning.
- Add `"Akash"` at the end.
- Remove `"Amit"`.
- Print the final list.

---

## 🔹 Assignment 3: Reverse Playlist

Create a `LinkedList` of 5 song names.

- Print the original playlist.
- Print the playlist in reverse order using `descendingIterator()`.

---

## 🔹 Assignment 4: Real-World Scenario - Train Coach Management

You are building a train coach management system.

- Create a `LinkedList` of 5 coach names.
- Add a new coach at the beginning.
- Add another coach at the end.
- Remove the first coach.
- Display all coaches.
